## Design Context

### Users
- Recruiters, HR managers, potential clients
- Mostly viewed during work hours, primarily on mobile devices
- Need to quickly assess professionalism and expertise

### Brand Personality
- **3 words**: Thoughtful, warm, confident
- Professional yet approachable
- Shows attention to detail and craft
- Reference: https://www.georgivedi.com/ - simple but professional

### Aesthetic Direction
- **Style**: Somewhat minimalist but NOT flat - needs texture and depth
- **Vibe**: Retro-futurism OR Brutalism (user's choice: "retro-futuristic and brutalism")
- **Feeling**: Confident, calm, thoughtful, warm
- **Avoid**: Generic flat design, corporate blandness, "AI slop" gradients

### Design Principles
1. **Add depth, not flatness** - Use shadows, subtle textures, layered elements to create visual interest
2. **Warmth through color** - Tint neutrals toward warm brand hue, avoid cold grays
3. **Confident typography** - Distinctive type scale with clear hierarchy, not Inter/System defaults
4. **Texture > Decoration** - Real texture/depth beats decorative icons and gradients
5. **Both themes required** - Light and dark modes, both with good contrast for colorblind users

### Technical Requirements
- Astro + TypeScript + React components
- Must pass WCAG contrast (especially for colorblind accessibility)
- Fluid type on marketing pages, fixed rem scale for app-like UI
- Container queries for component responsiveness
- OKLCH color functions, not HSL

### Anti-References
- Flat design with no depth
- Pure gray neutrals (tint toward brand hue)
- Inter/Roboto/system fonts as display
- Cyan-on-dark, purple gradients (AI slop)
- Decorative icons above every heading

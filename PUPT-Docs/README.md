# Portfolio Website Design System

Дизайн-система для сайта-портфолио, созданная в Pencil на основе [geettrivedi.com](https://www.geettrivedi.com/).

## 📁 Содержимое

- **portfolio-design.pen** — основной файл дизайна Pencil
- **Скриншоты экранов:**
  - `ZMBZP.png` — Home (главная страница)
  - `Ytnbo.png` — About Me (обо мне)
  - `DpACZ.png` — Work Experience (опыт работы)
  - `lOtWQ.png` — Projects (проекты)
  - `f5zyC.png` — Skills (навыки)
  - `XTYJ6.png` — Contact (контакты)

## 🧩 Компоненты

### NavDot
Навигационная точка в боковом меню (10×10px, круглая).

### SkillTag
Тег навыка с текстом (padding: 6×12px, radius: 6px).

### ExperienceCard
Карточка опыта работы с должностью, компанией и датами.

### ContactLink
Карточка контакта с иконкой и текстом.

### Sidebar
Вертикальное боковое меню с навигационными точками (64px ширина).

### ThemeToggle
Переключатель темы (светлая/тёмная).

## 📐 Структура экранов

Все экраны имеют единую структуру:
- **Ширина:** 1440px
- **Высота:** 900px
- **Сайдбар:** 64px (слева)
- **Навбар:** 72px (сверху)
- **Контент:** остальное пространство с padding 60-80px

## 🔗 Интеграция с кодом

Дизайн-токены синхронизированы с:
- `tokens/primitives.tokens.json`
- `tokens/semantic.tokens.json`
- `src/styles/tokens.css` (генерируется через Terrazzo)

## 🚀 Использование

1. Откройте `portfolio-design.pen` в Pencil
2. Используйте компоненты из библиотеки для создания новых экранов
3. Экспортируйте дизайн в PNG/SVG для передачи разработчикам
4. Обновляйте токены в `tokens/` при изменении цветов/размеров

## 📝 Примечания

- Дизайн создан для тёмной темы (светлая тема требует отдельной проработки)
- Все компоненты переиспользуемые (reusable: true)
- Навигация реализована через точки в сайдбаре + текстовое меню сверху
- Адаптивность под мобильные устройства требует дополнительной проработки

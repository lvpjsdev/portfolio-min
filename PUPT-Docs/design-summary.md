## 🧩 Компоненты UI-системы

### Созданные компоненты (7 шт.)

1. **NavDot** — навигационная точка (10×10px, круглая)
2. **SkillTag** — тег навыка (padding: 6×12px, radius: 6px)
3. **ExperienceCard** — карточка опыта работы
4. **NavItem** — элемент текстовой навигации
5. **Sidebar** — боковое меню (64px ширина)
6. **ThemeToggle** — переключатель темы
7. **ContactLink** — карточка контакта с иконкой

Все компоненты помечены как `reusable: true` и могут быть переиспользованы.

### Типографика

**Шрифт:** Ubuntu (с fallback на system fonts)

**Размеры:**
- Hero: 96px (bold) — главный заголовок на Home
- H1: 48px (bold) — заголовки страниц
- H2: 36px (bold) — подзаголовки
- H3: 18-20px (bold) — заголовки карточек
- Body: 16px — основной текст
- Small: 13-14px — метаданные, теги

**Line Height:**
- Заголовки: 1.0-1.2
- Основной текст: 1.4-1.7

### Отступы

- `spacing-xs`: 4px
- `spacing-sm`: 8px
- `spacing-md`: 16px
- `spacing-lg`: 24px
- `spacing-xl`: 40px
- `spacing-2xl`: 64px

### Радиусы скругления

- Карточки: 12px
- Теги: 6px
- Кнопки: 20px
- Точки навигации: 9999px (круг)

## 🔗 Интеграция с кодом

### Синхронизация токенов

Дизайн-токены синхронизированы с:
- `tokens/primitives.tokens.json` — примитивные токены (цвета, размеры)
- `tokens/semantic.tokens.json` — семантические токены
- `src/styles/tokens.css` — CSS-переменные (генерируется через Terrazzo)

### Использование в коде

```css
/* Цвета */
background: var(--color-primitive-midnight-violet);
color: var(--color-primitive-tiger-flame);

/* Отступы */
padding: var(--spacing-lg);
gap: var(--spacing-md);

/* Радиусы */
border-radius: var(--border-radius-lg);
```

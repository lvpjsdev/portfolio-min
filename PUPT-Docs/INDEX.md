## 🚀 Быстрый старт

### Для дизайнеров

1. Откройте `portfolio-design.pen` в Pencil
2. Изучите компоненты в библиотеке
3. Используйте компоненты для создания новых экранов
4. Экспортируйте в PNG/SVG для передачи разработчикам

### Для разработчиков

1. Прочитайте [README.md](./README.md) для общего понимания
2. Изучите [design-tokens-guide.md](./design-tokens-guide.md) для работы с токенами
3. Используйте [components.md](./components.md) как справочник по компонентам
4. Интегрируйте токены из `tokens/` в ваш проект

### Для менеджеров проектов

1. Прочитайте [design-summary.md](./design-summary.md) для полного обзора
2. Проверьте раздел "Что реализовано / что требует доработки"
3. Используйте рекомендации по приоритетам для планирования

## 📦 Интеграция с проектом

### Файлы токенов в проекте

```
tokens/
├── primitives.tokens.json    # Примитивные токены
├── semantic.tokens.json      # Семантические токены
└── ...

src/styles/
├── tokens.css               # Генерируется из tokens/
└── globals.css              # Глобальные стили
```

### Команды

```bash
# Сборка токенов
npm run build:tokens

# Запуск dev-сервера
npm run dev

# Сборка проекта
npm run build
```

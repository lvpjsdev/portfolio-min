## 🎨 Ключевые особенности

### Свернутое состояние (Collapsed)
- Компактный вид (180px высота)
- Название проекта + подзаголовок
- Краткое описание (2-3 строки)
- Теги технологий
- Chevron вправо →

### Развернутое состояние (Expanded)
- Полное описание проекта
- Секция Preview со скриншотом (320px)
- Список всех технологий
- Кнопки "Live Demo" (оранжевая) и "View Code" (серая)
- Chevron вниз ↓

## 📐 Спецификации

### Размеры
- Width: 700px (или fill_container)
- Collapsed padding: [20, 24]
- Expanded padding: [24, 28]
- Corner radius: 12px
- Gap: 12px (collapsed), 16px (expanded)

### Типографика
- Название: 18px (collapsed), 22px (expanded), bold
- Подзаголовок: 13px (collapsed), 14px (expanded)
- Описание: 14px, line-height 1.6
- Теги: 13px
- Кнопки: 14px, bold

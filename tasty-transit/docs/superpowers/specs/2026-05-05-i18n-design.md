# i18n Design for Tasty Transit

## Overview
Add internationalization support to the Tasty Transit Astro project with English and Russian languages using Astro's built-in i18n features.

## Decisions
- **Framework**: Use Astro's built-in i18n (v6.x+)
- **Languages**: English (default), Russian
- **Routing**: URL prefixes for ALL languages (`prefixDefaultLocale: true`)
  - `/en/about`, `/ru/about`
  - Redirect `/` → `/en/`
- **Translation storage**: JSON files in `src/locales/`
- **Translation usage**: Helper function `getTranslations(lang)` in `.astro` files

## File Structure Changes

### Current → New
```
src/pages/index.astro → src/pages/[lang]/index.astro
src/pages/about.astro → src/pages/[lang]/about.astro
src/pages/projects.astro → src/pages/[lang]/projects.astro
src/pages/contact.astro → src/pages/[lang]/contact.astro
src/pages/experience.astro → src/pages/[lang]/experience.astro
src/pages/skills.astro → src/pages/[lang]/skills.astro
```

### New Files
```
src/locales/en.json - English translations
src/locales/ru.json - Russian translations
src/i18n/translations.ts - Helper function
```

## Astro Config Changes

`astro.config.mjs`:
```js
import { defineConfig } from 'astro';
import react from '@astrojs/react';

export default defineConfig({
  integrations: [react()],
  i18n: {
    locales: ['en', 'ru'],
    defaultLocale: 'en',
    routing: {
      prefixDefaultLocale: true
    }
  }
});
```

## Page Template Pattern

Each page file (`src/pages/[lang]/about.astro` etc.):
```astro
---
export function getStaticPaths() {
  return ['en', 'ru'].map(lang => ({ params: { lang } }))
}
const { lang } = Astro.params;
const t = await getTranslations(lang ?? 'en');
---
<!-- Use t.navigation.home, t.home.greeting etc. -->
```

## Language Switcher

Add to `src/layouts/Layout.astro`:
- Shows current language
- Links to same page in other language(s)
- Uses `Astro.currentLocale` to determine current lang

## Redirect Root to Default Language

Create `src/pages/index.astro` (or middleware):
```astro
---
import { redirect } from 'astro:actions';
return redirect('/en/');
---
```

## Success Criteria
1. All pages accessible at `/en/...` and `/ru/...`
2. Text content comes from JSON files, not hardcoded
3. Language switcher works on all pages
4. Root `/` redirects to `/en/`
5. No broken links or missing translations

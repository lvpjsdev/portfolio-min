🚀 How to Use

<!-- Favicon in HTML head -->
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">

<!-- Logo in header -->
<img src="/logo.svg" alt="Leonid Petrov" width="120" height="120">

<!-- CSS text logo -->
<style>
  .logo-text {
    font-family: 'JetBrains Mono', monospace;
    font-weight: 700;
    font-size: 2.5rem;
    background: linear-gradient(90deg, #f46036, #5b85aa, #414770);
    -webkit-background-clip: text;
    -webkit-text-fill-color: transparent;
    letter-spacing: -2px;
  }
</style>
<div class="logo-text">LP</div>

Convert SVG → PNG (if needed)
